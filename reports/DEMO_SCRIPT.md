# Demonstration script

1. Start the app with `streamlit run app.py`.
2. Open Project Overview and state the research question and interpretation boundary.
3. On Synthetic Experiment, change noise or shock count and explain the independently calibrated threshold.
4. On Shock Detection, select an origin and responder and inspect event-level response strengths.
5. On Inferred Network, compare true and inferred graphs and identify false positives or false negatives.
6. On Method Comparison, show the generated mean and standard-deviation table without assuming SRCS wins.
7. On Real-Data Analysis, use the cached dataset, show detected shocks and inspect ranked candidates.
8. Close on Methodology and Limitations, emphasizing that rankings are evidence for investigation rather than causal conclusions.

Recommended duration: 7 to 10 minutes. Keep `reports/results/` generated before the demonstration so no long experiment is required live.
